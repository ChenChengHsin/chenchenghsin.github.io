## 學習規劃辦公室

先講結論：我覺得所有學生都應該要去學習規劃辦公室(AAO)一次。

學習規劃辦公室的主要目的是希望學生能夠適才適性發展、引導學生進行修課規劃；簡單來說呢，就是你要在網路上面先填表單預約時段，說明你想討論的事情或問題；到了現場總共會有一小時的時間，規劃師會和你討論並嘗試幫分析各種選擇。多數學生的問題可能是出國交換、雙轉輔、校學士領域專長等等的修課問題，不過像是覺得不知道以後想做什麼、很怕被AI取代諸如此類的各種問題，也完全可以是一次討論的主要內容。

我自己在升大二的暑假有去過一次，當時是討論雙主修規劃上的問題，體驗非常的好。其實去AAO並不是期待規劃師給你一大堆建議，更多的是引導你讓你能夠更認識自己的想法以及價值觀，從而做出對未來的規劃，具體規劃師怎麼協助我想這因人而異，總之如果有時間的話，去一次就對了。

另外，我目前也是AAO的同儕顧問，如果有電資學院的學生的話，會媒合到我也說不定（？當然如果你有電機、資工雙主修、轉系、輔系，或是任何其他問題想跟我討論，也歡迎直接去我的首頁填表單告訴我！

附上AAO官網給有需要的人參考：https://aaoffice.ntu.edu.tw/


## 交換學生

台大有非常多間合作的學校可以申請交換！通常來說如果你想要某一年(或某學期)想去交換，那麼你要一年前申請，然後是看兩年前的成績(非常合理畢竟你申請的那年成績根本還沒出來)，如果要交換的話多數人會選在大三或大四，也就是大二或大三的時候就要開始申請了，想交換的同學一定要特別留意時間，當然英文檢定什麼的也要看好標準。

不過接下來要講個資訊系學生可能有點吃虧的地方，就是申請交換名額通常不多，但GPA又是全校一起比的(系上某些必修那個A+%真的是頗低)，所以在選學校的序位上面可能會比較困難一點（？不過還是有非常多很優秀的學長姐申請到心儀的學校，這邊只是想提醒要申請的同學GPA還是要顧才可以申請到理想的學校

另外去交換修課是可以算在畢業學分(通常是一般選修，不過還是要看學校和原系的規定)，不過成績不會算在畢業的GPA裡面，所以聽起來還滿划算的。一樣附上學校官網給有需要的人參考

台大交換官網(有非常多同學的心得可以看)：https://studyabroad.ntu.edu.tw/exchange-student/

# 雜七雜八但你該知道的事情

各位CSIE的新生，以下這些東西真的100%會用到，直接學就對了<span class="spoiler spoiler-white" tabindex="0">我當初就是什麼都不會，一進系上覺得自己好像有未受文明浸染的澄清？</span>

## IDE

99%的人有在用VS Code，應該是公認最方便也最好用的IDE了，如果你還在用其他的東西不用懷疑，直接下載就對了，希望你會發現它好用的地方\
一樣附上連結給有需要的同學：https://code.visualstudio.com/

## Document Editor

如果你還在用word的話<span class="spoiler spoiler-white" tabindex="0">應該沒有人是用google document的吧</span>，相信我你用過以下的東西你就回不去了

這邊推薦三個比較主流的 Document Editor
- Hack md：是寫Markdown語法非常好上手，想要公開發表筆記或是轉成HTML都很方便，不過如果沒有付錢的話是無法匯出成pdf的，有匯出md的需求的話可以下載Obsidian，也是挺不錯用的。

- LaTeX：應該是其他理工學系最多人使用的Document Editor，稍微不太好上手，不過如果有模板的話，也是無痛入手一個高排版品質還有能處理複雜數學公式的編輯器。

- Typst：不專業統計，我自己覺得系上越來越多人在用，但我好像沒有聽過其他系的人用這個編輯器 ~~我覺得是我朋友太少~~。Typst相較LaTeX編譯速度快了不少，報錯提示也比較簡單直覺，我個人目前寫作業就是用Typst。

## UNIX 指令

不知道該怎麼強調這個的重要性，但如果這整篇文章要選兩個最重要的事情應該就是這邊了吧(另一個在樓下)。還記得我剛進系上連powershell是什麼都不知道，更不用說灌WSL練習相關的東西，不過如果想單純隨便亂玩的話，工作站也是個練習的好地方，總之肯定是越早熟練越好，通常是一邊玩一邊記指令<span class="spoiler spoiler-white" tabindex="0">如果你跟我一樣是因為要寫NASA HW0才開始學的話好像會翻車，但多練習幾次肯定是沒問題的</span>

網路上的教學非常多，這邊附上經典鳥哥網站供參：https://linux.vbird.org/

## Git / GitHub

重要程度跟樓上差不多，就是非常重要。

Git是一套安裝在電腦裡的版本控制軟體，你可以想像當你有個版本其實已經可以AC只是你想追求一下其他地方，於是你爆改了一大堆程式結果CE，這時候版本控制就很重要了，有Git你就可以隨時退回原本的版本，不用一直後悔剛剛自己把Code都改壞了。

GitHub則是託管Git儲存庫的雲端平台，讓你可以把程式碼備份到雲端，方便跟其他人遠端協作。其實重點一樣是版本控制，只是當多人一起協作的時候會多一些指令跟要注意的事情，細節就留給讀者自己看吧，不管是一個人兩個人還是很多人，這邊想強調的是直接開始用就對了。

一樣附上官網連結：https://git-scm.com/、https://github.com/
