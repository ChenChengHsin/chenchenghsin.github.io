# 系訂必修

## 資料結構與演算法( DSA )
> * 授課教授：林軒田 / 蔡欣穆合授
> * 學分：3
> * A+%：1.8%(左右)
> * 每週課後花費時間：20+hr
> * 收穫：100/5
> * 評分方式：Writing asst10%、Activity10%、Programming asst20%、Mid&Final60%
> 
> *HT：又到了大家最喜歡的fire side chat時間，(以下省略3000字)...*\
> *HM：資訊系的大家好像不擅長把話說清楚？*

這堂課就是資訊系的招牌必修資料結構與演算法，簡稱DSA。如果要用一句話給這門課評價的話，我們會說我們有堂很棒的必修課，推薦所有想學好程式的人都來上這門課。

這門課真的太多可以講了，像是因為時間真的不夠或是題目太難，我們常常會在系館聽到感性理解、精神AC這種話，意思就是我只有看完LLM給的解答或是我覺得我會了，實際考出來會不會寫那是完全不好說。雖然在修的過程會一直抱怨東抱怨西，但修完回來看真的覺得有很多事情還滿棒的。


### Homework assignments

首先就來講作業的部分吧！一講到DSA作業一定是可以引起所有資訊系學生的PTSD，各種大小作業會一個接著一個來，一週花20+hr真的不是誇飾 ~~當然，如果你用LLM就是另外一件事了~~。
一份作業會是四大題，兩大題Handwriting兩大題Programming
* Handwriting Part：大多數時候寫得滿開心的，通常是帶我們刷一些經典的題目，有些真的出得超級好，像是KMP的那份作業我寫完真的完全重新理解KMP這東西；不過也有部分題目難度真的是完全大超出我覺得正常學生想的到的程度，就當是欣賞一下這些通靈的做法了。
* Programming Part：P3通常是要我們實刻一個資料結構，P4就比較偏向應用演算法的題目，一題大約300行左右，花多久時間就因人而異了，有時候看pseudo code覺得好短，結果實際轉成C會把自己累個半死。

另外作業還有剛開學拿到的HW0，還有時不時跑出來一下的mini HW
HW0：總共有十題，是用來確認你會基本的C語言，題目計程大多數都寫過了，就算你計程停修應該也沒什麼問題，如果是外系同學想要來修這門課會建議至少知道遞迴然後會操作Linked list應該就可以了。\
Mini HW：正如其名非常mini，跟一般的作業完全沒得比，大概就是把課堂上教的最基本的資料結構或演算法按照pseudo code寫出來，不過我還滿支持有mini hw的存在，雖然我知道很多強者可能會覺得太簡單或太水，但對於沒有太深程式經驗的同學來說(我)，這真的是有幫助的。

因為作業真的太難了，如果有什麼問題不會的話，去找TA就對了！這門課的TA資源超級豐富，總共有超過20位TA，週一到週五都有超級多時段的TA Hour可以去，我在TA Hour把滿多觀念弄清楚的，助教人也都很好，還順便認識了一些學長姐，超級愛TAs。


### Class Activities

想不到在必修課上還能玩遊戲吧，歡迎來修DSA。
下半學期總共會有三週的時間沒有上課而是進行各種活動，這三週的上課內容就變成要回家自己補影片 (雖然下半學期就算沒有活動，課也是永遠上不完然後叫大家回去看影片)，雖然這讓下學期的loading變得超級重(別忘了作業是不會停的)，但我還是覺得能有這些不一樣的活動讓大家學習玩樂也是挺好的，至少我自己玩得還算開心。

大地遊戲 : 形式就是你在營隊或是活動會玩到的大地遊戲，只是遊戲內容變成都跟DSA有關，總共五關然後各個小隊去跑關，必須說，能在必修課玩到大地遊戲還滿幸福的，我在猜程式碼那關只開一行就運氣爆棚猜到min heap，還滿開心的。

SWE : 軟工的活動則是要請各組用任意的方式實作呈現一種資料結構或演算法，在某天上課各組用類似攤位的形式介紹自己組的作品給別人。這個活動我個人的體驗不太好，主要是因為大部分的組員不想做比較有挑戰性的題目，又有同學直接用AI幾乎把東西做完，也有很多人什麼都沒做搭順風車，但當天看到其他組眼睛發光的介紹自己的作品，加上很多真的超級精美的動畫或厲害的演算法，就覺得這個活動還滿有意義的，至少當天逛展逛得很開心。

Kahoot :沒錯，就是Kahoot，幫大家複習一下簡單的觀念，但我覺得有些題目好像時間太短了，至少我自己想不完。

### Don't Sleep Anymore !

上半學期是由軒田學長上課，下半學期則是欣穆老師，兩個人的風格還滿不一樣的。
軒田學長今年每週會花一節課左右來進行Fireside Chat，喜歡的人就聽，不喜歡就先走，聽學長聊聊他的想法還挺不錯的 ~~雖然我很多時候都完全沒空聽他聊天因為其他科目準備完蛋了~~；下半學期欣穆老師會講簡報然後做一些筆記我覺得還挺不錯的，如果沒有睡著的話可以跟著做一些練習。

這門課真的是讓大家睡不好的一堂課，有時候寫程式寫到上頭沒AC不想睡覺的話，可能就真的不用睡了，常常禮拜六日都在煩惱P1P2想不到P3P4(Programming Part)寫不出來，但是真的覺得自己學了滿多東西的，好課推薦給所有想學好程式的人！<span class="spoiler spoiler-white" tabindex="0">但你可能要準備好你的探索學分以及巨量的時間：）</span>

大一寒假看了其他人的修課心得，感覺這門課不太需要先備知識(修完的體驗也確實是如此)，就決定先來修了！

系上的機率分單(林守德)雙(洪一平)兩班，當初爬了一下文就決定寄信加簽雙班，結果就是音訊全無。開學發現守德班只要選課系統登記就可以上，就決定網路上先登記守德班，然後去一平班等加簽規則。
第一堂機率課完全是把我嚇瘋，除了雙班教室人多到滿出來，有學長通風報信發現單班教室在隨機點人(我已經簽到單班)，完全不知道被點到會怎麼樣的我立刻跑回去單班上課，結果聽著聽著就發現好像單班老師講話的方式也滿有趣的（？~~雙班我聽兩句就有點想睡了~~

又隔了一週再聽了一點課+知道作業的內容後，就決定留在單班了(我還是有拿到雙班的授權碼)。<span class="spoiler spoiler-white" tabindex="0">聽到隔壁班同學說的各種神奇事蹟+這班超級甜的成績，如果明年計分規則不變我大推單班。</span>


### 上課

SD Lin上課是講他自己做的投影片，每週上課開始會簡單複習一下上週的內容。
機率一週是三堂課，但第三堂是助教課(通常是講幾題同學上週的題目)，守德講投影片的速度真的是飛快，就算只有隔壁班2/3的上課時間，進度還是比隔壁班快了不少，常常我覺得我還沒理解完上一頁的式子，就已經在講下一頁的東西了。

另一個有趣~~讓人不要睡著~~的事情，就是老師會用線上抽籤抽人回答問題，結果到學期末附近去上課的人真的太少了就變成直接點人回答，不過答案通常都會寫在pdf上面，被點到沒出現也不會被算缺席或扣分。


### 作業

今年單班機率最大的特色肯定是作業了，總共進行9次，每次最高3分(Cap 20)；今年作業的形式是要針對當週上課的內容，自己出一道題目試圖讓LLM答錯，並讓LLM透過指定的prompt對我們出的題目進行四個面向的評分(關聯性、鑑別度、原創性、模糊度)，這四個面向的評估怎麼轉換成實際的分數有點複雜我就不列了，基本上每次作業大家應該都能得到2~3分。

我個人覺得作業的立意非常好，但是實際執行上效果可能有打點折扣。
因為SD上課真的講太快了，所以常常要回家消化一下內容，原本作業應該是期望大家自己消化完內容後再自己設計題目，然而實際執行起來卻是常常自己出的題目會被扣分，用LLM出題卻比較容易拿滿，變成努力的人分數可能會比較低（？當然也很可能是因為我自己設計的題目不怎麼巧妙，我看到某些同學的題目，真的是超級大佩服，完全看起來就是自己出的又設計得非常好，能寫到其他人這麼有創意的題目我超級開心。


### 期考

今年期考教授有提前說，大概4成的題目是由同學出得好題目組成(前一週會公布好題目)，我原本想說把同學們出的好題目寫一寫就差不多了，結果考前一天看了考古題才感覺大事不妙，因為考古題很多重複的題目，所以我其實應該要多寫幾年的題目~~但是我連公開的好題目都寫不太完~~，最後就是直接把一堆題目丟給LLM請他快速教我。

期末考的題目組成和期中考差不多，但是因為週次變多/大家越來越會出題目，導致好題目題庫的題數大幅增加，數量完全增加到一個我寫不完也不想寫的程度，去問了幾個朋友也都說沒有寫多少就上去考了(當然這很可能是因為大家期末都有更慘的其他科目)。

考卷是12題(左右)寫三個小時，滿分120(Cap 100)。總之，如果想拿高分，多刷幾年考古題應該是非常有幫助。

### 作業分組

珮芸的作業仍舊維持一貫的風格跟難度，可能是因為希望助教不要批改那麼多份作業，或是覺得下學期的單元比較困難希望大家多討論，所以這學期的作業變成4~6人一組，每題助教只會抽組內一個人的作答內容批改，分數則是整組相同，同時每次作業要錄影或是紀錄討論的過程上傳到COOL上面。

雖然是說每組都應該要有討論，但討論的程度我想就差異滿大的，從只有對個答案到每次花4~5個多小時的都有，而我們就是那個每次都花超級多時間的組。

我真的超級愛我的組員，很常我上課根本就一知半解或是根本沒聽懂，能遇到一群人可以一起討(教)論(我)題目我超級大感謝，加上作業真的是很難，還能遇到一群不用LLM寫作業的人真的超級幸運，每次討論我都有種，歐～原來這個地方是在講這個事情歐，我的組員簡直可以說是我的普物助教了，超級愛他們讓我在考試的時候明顯感受到自己是真的有手推過這些東西，寫起來安心不少，也讓我這學期多學到很多東西。

> *同學們，你們是不是高中都拿前三名阿*

這學期終於有完整的馨瑩英文課可以上了！馨瑩的課大致圍繞著三件事情：同學上台報告與討論、馨瑩帶討論活動、寫短文與練習英聽，至於打分數的部分就是多發言必定A+，完全不用擔心考試或是作業什麼的會被扣多少分，記得準時上課點名，開心發言開心玩就對了。

### 報告

馨瑩的課程會要我們自己分組，分組好就一整年不會換了，報告是以組(4人)為單位上台報告抽到的短篇故事或指定主題。

通常一次報告約60分鐘(一節課多一些)，然後接著馨瑩會帶大家討論這篇小說值得討論的問題，~~正常大家應該要先回家看過一次文章，但我很常沒看~~ 我覺得討論的問題都滿不錯的，雖然有時候會很想做自己的事情，但大家都會乖乖專心上課。

### 活動

因為每次上課都會先點名，經過一年大致上是處於一個知道每個人的名字但幾乎沒講過什麼話，馨瑩這學期帶的活動會強制幫大家換組討論我覺得很棒！讓我多認識了好多好多人，雖然說是說要用英文討論一些問題，但後面都變成用中文跟大家聊天，還滿開心的


### 話劇

另一個特色活動當然就是話劇啦，話劇的形式是針對抽到的故事進行改編，然後以組為單位上台演個大約5分鐘左右的話劇。

因為上學期大家都已經演過一次了(很熟悉形式)，這學期大家真的是八仙過海，每個人都卯起來演，超瘋我很愛，除了正常的演戲之外，還外加了一大堆道具像是玩具槍、抽籤筒......

我們這組應該算是超級超級瘋(包含我們應該只約了一兩次就上台了)，我們直接把一篇故事跟阿拉丁結合在一起，然後我還上台演魔術師變了個小魔術，加上一大堆神奇配樂，場面是非常的歡樂，總之那天看大家的表演還有自己的表演是真的滿開心的。

# 全校性通識

## 國民法官必備之基礎鑑識科學
> * 授課教授：翁德怡&其餘演講講師
> * 學分：2
> * A+%：63.3%
> * 每週課後花費時間：1小時
> * 收穫：4/5(以通識來說)
> * 評分方式：每週心得65%、期末報告30%、舉手提問5%
> 
> *讓我們掌聲歡迎今天的講師*


這堂課就是台大數一數二熱門的通識課程，上完之後的心得就是推薦大家來修！
如果你直接抽到這門課那你絕對是天選之人，沒抽到的話要注意！加簽的方式是要寫一篇推理小說或社會案件的心得跟修課動機

國民法官其實是演講課！上課的模式是每週會有不同領域的專家來分享(檢察官、鑑識專家、毒物學教授、兒少醫師......)，內容真的是五花八門包羅萬象，有的老師真的很會講！會讓人有種想去修法律系課的衝動，當然也有老師講了兩節課但我什麼都沒聽進去的時候，但絕大多數我都聽得滿開心的~~但不包含等一下要微積分小考或明天要期中考的時候~~，除了單純知識上的吸收，更喜歡老師帶一些道德或司法相關的思辨，覺得都滿有意思的。

而作業的部分則是每週寫心得，沒有出席分數，但如果你不出席的話應該是完全寫不了心得，所以到課率感覺還滿高的，老師也是很認真的在改作業，主要就是希望你有寫出一些看起來真的有來上課，不是直接把簡報丟給LLM讓它生出東西直接交而已。


唯一覺得不太好的制度是有5分的舉手提問加分，每次提問+0.5，會從提問次數少的同學開始先問，而這個結果就導致下一堂有課程的同學基本上不可能提問超過兩次，甚至有聽到同學為了加分留到七點，不過最後發現，如果你的心得跟期末報告夠高，都不提問也會A+，不過這部分要修課的同學可能要再留意一下。

這門課在我心中絕對是高品質的通識課程，認真聽課的話絕對是可以帶走一些東西的。


## 諾貝爾生醫獎得主的啟示
> * 授課教授：饒梓明
> * 學分：3
> * A+%：29.1%
> * 每週課後花費時間：0小時
> * 收穫：0/5
> * 評分方式：課堂參與10%、出席20%、課後測驗30%、期末報告40%
> 
> *同學們，可以分享一下你聽完之後的收穫嗎*
 
超級大水課，前三週是加退選不列入成績、期中(末)考前+期中(末)週全部放假、期間還有一次外賓演講可以在家線上上課，全部加一加16週的課只上了8次。

每週Zuvio簽到簽退，課間大約10分鐘討論&上台(輪流)，課後寫五題選擇題，你就會得到這堂課的學分。如果單就課堂內容，完全沒有收穫、體感上也不太甜(期末報告大家都莫名的低分)，大不推這門課。

講了很多壞話之後就來講一下這門課在做什麼吧：\
這堂課正如課名，是希望大家能從諾貝爾生醫獎得主的人生經歷裡面得到一點啟發，每週老師會介紹兩年的諾貝爾生醫獎得主，包含他的研究內容、生平背景等等，然後會留約25分鐘的時間，讓各組(8~9人)討論一下有什麼收穫、有什麼能夠補充的內容，最後各組選兩位上台分享討論內容。
另外，諾貝爾這堂課非常需要你舉手回答問題，總共佔10分，所以如果你一次都沒有回答的話，你的等第就是從A開始往下掉，不過也不用擔心，老師的問題通常都是非常簡單甚至是發表自己的看法即可，所以如果敢發言的話，10分一定是可以拿滿的。

這堂課唯一的亮點就是遇到了超級棒的組員！
資訊系的課其實不太有機會進行一些討論，更不用說9個人要一起做一份期末報告。其實我一開始真的很擔心分工還有下決策的問題，結果有個大四的學姊真的是把大家帶的超級好，不管是在討論的時候把很多資料都整理好，決定主題之後也把框架跟分工訂的非常有條理，讓整個報告過程我覺得都滿順利的。
另外還要超級感謝組裡面再分成同個小組的組員！不管是課間討論還是期末報告都超級順利，然後原本有些是我應該要完成的工作他也幫我很多，還有一些零碎的事情就不寫出來了，總之超級感謝他！

雖然諾貝爾這堂課真的大不推，但是遇到很棒的人讓我覺得自己也還滿幸運的
